    What is an agent?

    An agent perceives its environment through sensors and acts on it through actuators to reach a goal. Every robot in this game repeats the same loop:

    Perceiveread the board
    ➜
    Decidesearch and evaluate
    ➜
    ✋Actplace a stone

    PEAS description of our Gomoku agent

    PerformanceWin (five in a row), stop the opponent's five, decide quickly
    EnvironmentThe board (9×9 to 15×15) and the opponent
    ActuatorsPlacing a stone on an empty crossing
    SensorsReading every cell of the board (empty, black or white)

    Compare: the vacuum-cleaner world

    Vacuum cleaner agentGomoku agent
    Percept[Location, Dirty or Clean]The whole board
    ActionsSuck, Left, RightPlace a stone on any empty cell
    GoalAll squares cleanFive stones in a row
    State space2 squares × 2^2 dirt = 8 statesUp to 3^225 boards on 15×15
    Opponent?No (single agent)Yes, adversarial (multi-agent)

    Same perceive → decide → act cycle, but Gomoku has a huge, adversarial state space. That's why it needs search and heuristics.

    Fully observablenot partially observable

    Both players see the whole board at all times.

    Deterministicnot stochastic

    Placing a stone always gives the same next board, with no dice and no luck.

    Sequentialnot episodic

    Every move changes what is possible later.

    Staticnot dynamic

    The board does not change while the agent is thinking.

    Discretenot continuous

    A finite number of cells, moves and board positions.

    Multi-agent, adversarialnot single agent

    The opponent's goal is the exact opposite of ours.

    Uninformed vs informed search: live experiment

    Uninformed (blind) search has no domain knowledge: it tries every empty cell and only recognises win or loss. Informed search uses a heuristic function and candidate move generation to look only at promising moves. Pick a board size and run all four searches on the same position (2 moves ahead):

    The number of states depends on the size of the problem

    There is no external dataset. The "data" is every board the agent can reach, and it grows with the board size. Press measure to run blind and informed search on each size:

    BoardCellsPossible boards (upper bound 3cells)Blind search (states)Alpha-Beta (states)

    Blind search grows roughly with cells² for each 2-move look-ahead. Informed search stays almost the same, because it only considers cells near existing stones.

    Fuzzy logic: how the AI judges your skill and picks your next opponent

    Bias: the first-move advantage

    In Gomoku, the player who moves first (Black) has a real advantage. Our measurements: with the same robot on both sides, Black won 11 of 12 Owl-vs-Owl games and 17 vs 14 Foxy-vs-Foxy games. Check it yourself:

    How the project keeps things fair

    • Fair rating: when you play White, the robot counts as 100 rating points stronger, so you are never punished for the colour you got.
    • Fair robot comparisons: Robot Battle swaps colours every game and replays each opening with both colours.
    • Your choice: you can always choose to move first.
    • Fair grading: accuracy compares each move with the best move available at that moment, the same for every player.
    • Right level for everyone: Smart Match (fuzzy logic) gives beginners easier robots instead of discouraging them.

    Transparency

    • The AI shows the moves it compared before every move, and says why it played.
    • Every grade can be explained: the report lists the exact moves behind it.
    • Honest limits: the robots do not learn from your games, and grading looks only 1 move ahead.

    Privacy and safety for kids

    • Only a first name is stored. No email, no password, no age, no location.
    • Everything stays on this computer (data/gomoku.db). Nothing is sent to the internet.
    • Players can delete all their data from the Scoreboard at any time.
    • No ads, no chat with strangers, no in-game purchases.

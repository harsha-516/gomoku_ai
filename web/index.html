What is an agent?

An agent perceives its environment through sensors and acts on it through actuators to reach a goal. Every robot in this game repeats the same loop:

👀Perceiveread the board
➜
🧠Decidesearch and evaluate
➜
✋Actplace a stone

PEAS description of our Gomoku agent

PerformanceWin (five in a row), stop the opponent's five, decide quickly
EnvironmentThe board (9×9 to 15×15) and the opponent
ActuatorsPlacing a stone on an empty crossing
SensorsReading every cell of the board (empty, black or white)

Same perceive → decide → act cycle, but Gomoku has a huge, adversarial state space. That's why it needs search and heuristics.

👁️ Fully observablenot partially observable

Both players see the whole board at all times.

🎯 Deterministicnot stochastic

Placing a stone always gives the same next board, with no dice and no luck.

🔗 Sequentialnot episodic

Every move changes what is possible later.

⏸️ Staticnot dynamic

The board does not change while the agent is thinking.

🔢 Discretenot continuous

A finite number of cells, moves and board positions.

⚔️ Multi-agent, adversarialnot single agent

The opponent's goal is the exact opposite of ours.

Simple reflex: reacts without a goal. Goal-based: chooses actions that reach the goal (five in a row). Utility-based: gives every board a number (utility) with the heuristic function and picks the best one.

Uninformed vs informed search: live experiment

Uninformed (blind) search has no domain knowledge: it tries every empty cell and only recognises win or loss. Informed search uses a heuristic function and candidate move generation to look only at promising moves. Pick a board size and run all four searches on the same position (2 moves ahead):

The number of states depends on the size of the problem

There is no external dataset. The "data" is every board the agent can reach, and it grows with the board size. Press measure to run blind and informed search on each size:

BoardCellsPossible boards (upper bound 3cells)Blind search (states)Alpha-Beta (states)

Blind search grows roughly with cells² for each 2-move look-ahead. Informed search stays almost the same, because it only considers cells near existing stones.
